# Les Marées d’Ambre

An offline iOS strategy game about an archipelago, asymmetric factions, and a fair weekly challenge.

## Project status

Prototype in development. The initial scope is a playable single-player game for iPhone and iPad, with local saves and no backend service.

## Design principles

- Sessions designed for mobile play.
- No progress lost because of an absence or a nighttime attack.
- Identical starting conditions for the weekly challenge.
- No pay-to-win advantages.
- Persistent multiplayer will be considered after the prototype is validated.

## Development

The project is built with SwiftUI and native Apple technologies. The iOS target and interface choices may evolve as the prototype develops.

Open `Marées/Marées.xcodeproj` in Xcode to explore the project.
